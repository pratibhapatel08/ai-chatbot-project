# AI Chatbot

A full-stack AI chatbot built using React, Node.js, Express, Ollama, and Redis.

## Features

- Real-time AI chat
- Hindi, English, Hinglish support
- Chat history support
- Redis caching for faster responses
- Responsive UI
- Loading animation
- AI response optimization

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js
- Axios

AI:
- Ollama
- Llama3

Database / Cache
- Redis


## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
