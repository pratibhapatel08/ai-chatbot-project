# AI Chatbot

A full-stack AI chatbot built using React, Node.js, Express, and Ollama.

## Features

- Real-time AI chat
- Hindi, English, Hinglish support
- Chat history
- Responsive UI
- Loading animation

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js

AI:
- Ollama
- Llama3

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
